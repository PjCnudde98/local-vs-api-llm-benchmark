Cost

At what volume does local pay off?

Cost per reply against replies per month. An API reply costs the same at any volume. A local box costs the same every month (hardware, hosting, ops hours), so its cost per reply falls as volume grows, until the box is full and a second one is needed. Where a local line drops below an API line is the break-even volume. Agent edit time is left out.
